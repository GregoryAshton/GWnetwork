What this is

Every gravitational-wave event in the GWOSC catalogues, linked to the arXiv papers that name it. The event list is built from GWOSC and extended by hand where a signal was reported elsewhere; the literature is found by searching the NASA ADS full-text index for every designation an event has ever been known by — including electromagnetic counterpart names like AT2017gfo and short forms like GW230529.

What a mention is

A mention is an occurrence of an event's name in the text of a paper we hold, recorded with its character offset, the section it appeared in, and the surrounding sentence. Nothing is inferred: if the string is not in the text, there is no mention.

A mention is not a citation, and the two sets differ more than you might expect. For GW170817, 9,775 papers cite the discovery paper and 11,313 name the event somewhere in their full text — but only 6,005 do both. Roughly 3,800 cite the paper without ever writing the event's name, and 5,300 write the name without citing that paper. Counting citations and counting mentions answer different questions, and neither answers who actually used the event — that is what the usage classification is for.

The data set is incomplete

Coverage is partial and openly so. Full text has been fetched for 1,975 of 13,904 papers (14%); for the rest only the abstract has been searched, so their mentions are undercounted. Each event page shows what we found against the number ADS reports, so the shortfall is visible rather than implied. Usage classification — whether a paper reanalysed an event, used its posterior samples, or merely cited it — has been run on a handful of papers as a sample, not the corpus. Treat every count here as a lower bound.
