What this is

Citation counts say which papers reference a discovery paper, not what they did with the event. GWnetwork links every gravitational-wave event to the papers that name it in their full text, then uses a large language model to classify how each paper uses each event — with a quoted sentence from the paper as evidence for every call.

A mention is an event's name (or any alias, including counterpart names such as AT2017gfo) found in a paper's text. Mentions are matched exactly, not inferred, and are not the same as citations: many papers cite a discovery paper without naming the event, and many name it without citing the paper.

Each paper–event pair is then labelled by its deepest use of the event:

strain analysis
analyses the detector data for the event
posterior samples
uses released parameter-estimation samples
published results
uses published measurements with their uncertainties
qualitative
discusses or builds on what the event showed
cited only
names the event in passing

and by roles — what the event is used for, such as a single-event study, a population, a test of general relativity, cosmology or dense-matter physics.

Where to go

  • Events — every event with its measured properties, filterable and sortable; each event's page lists the papers that mention it, grouped by how they use it.
  • Papers — every paper in the corpus, with the events it mentions and how it uses each.
  • Explore — charts across all events: where attention sits in the mass plane, how it builds over time, and whether loud events get more of it.
