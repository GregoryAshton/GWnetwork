Three views of how the literature covers the event catalogue. Every mark links to its event.

“Using its data or results” means the classifier found the paper analysing the event's strain, using its released samples, or using its published measurements — not just discussing or citing it. Those labels are a first pass (see the front page for their measured accuracy).

Across the mass plane

298 events with both component masses measured. Marker area is proportional to the number of papers mentioning the event; shape and colour give the compact-object class. Axes are logarithmic.

Mass class uses a 3 M☉ threshold and ignores measurement uncertainty, so events near the line are genuinely ambiguous — GW190814's 2.6 M☉ secondary is the well-known case. See the table view for the underlying numbers.

Over time

Papers mentioning the event, per year and stacked. The ten most-mentioned events are named (the same ten, in the same colours, for both counts); everything else is grouped. Hover a band for its event and total. Papers are dated by their latest arXiv version.

A paper counts once per event per year. Totals reflect what we have extracted, not the full literature — see the ADS ceiling on each event page.
